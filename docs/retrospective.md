# Project Retrospective

**Project Name:** Personal Portfolio Website

*Based on the three key questions from PMUPM Chapter 7.*

## What Went Well

The HTML structure came together cleaner than previous projects! Taking the time to plan out the semantic layout before writing any code made a noticeable difference. I wasn't second-guessing myself halfway through about whether a section should be a `<main>` or a `<div>` because I'd already thought through the structure in advance.

## What Went Wrong

The CSS took way longer than I budgeted for, which is exactly the risk I flagged in `plan.md`, so at least I saw it coming... Getting the layout to feel like something I was actually happy with took multiple rounds of adjustments, and there were a few moments where I had to remind myself to stop chasing perfection and just get it done. The visual inspiration from sharyap.com set a high bar in my head that plain HTML and CSS can't fully match, so there was some mental adjustment involved in accepting a simpler result.

## What I'd Do Differently

If I ever went back in time to do this project differently, it would be to simply reel back my expecations for the CSS as much as I enjoying styling. It's extremely easy for me to just keep tweaking and editing the CSS, since I was never fully satisfied with it. I kept asking myself questions like "Is this too harsh on the eyes? Does this read awkwardly? How would this look to a passerby judging the site, it looks so plain?" The inspiration I got gave me almost too much, I wanted my site to match this grand view I had in my head for it, but lacked the knowledge and knew that it was extremeley out of scope for the assignment.
