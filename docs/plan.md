# Project Plan

**Project Name:** Personal Portfolio Website

## Risk Analysis

Using the TAME framework from PMUPM Chapter 4, here are the identified risks for this project.

### Risk 1: CSS Styling Taking Longer Than Expected

| Metric | Score |
| --- | --- |
| Impact (1–5) | 3 |
| Probability (1–5) | 4 |
| Actual Risk Score | 12 |

I'm more familiar with simple HTML rather than CSS, so getting the layout and styling to look the way I want it to is probably where I'll spend the most unplanned time. My inspiration site has a very distinctive look that I want to translate into basic CSS which could take longer than I expect.

**TAME Strategy: Mitigate**  
I'll draft how I want the site to look beforehand and scope down the visual ambition early if needed. I'll also set a time limit on styling and move on after it's hit.

### Risk 2: Scope Creep from Wanting to Add More Features

| Metric | Score |
| --- | --- |
| Impact (1–5) | 2 |
| Probability (1–5) | 5 |
| Actual Risk Score | 10 |

Knowing myself, another risk I'll likely have is that I'll want to keep adding onto the website CSS wise and end up losing track of the original assignment scope. Though this is quite probable, I don't think I'll be deducted major points as long as I stick to basic CSS and fulfull the original project requirements first.
